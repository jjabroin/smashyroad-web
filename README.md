# BLOCKY RACER — 복셀 3D 트랙 경주

🎮 **플레이:** https://jjabroin.github.io/smashyroad-web/

복셀 스타일 3D 서킷에서 겨루는 트랙 경주 게임.
차고에서 차·트랙을 고르고, 결승선에 먼저 도착하세요.
부딪힐 때마다 대미지를 입고, HP가 0이면 폭파 탈락합니다.

## 온라인 멀티플레이 (P2P 직접 연결)

기기끼리 직접 연결(WebRTC)합니다. 호스트가 물리·충돌·아이템 전체를
시뮬하고 20Hz로 뿌려서 4명 화면이 일치합니다. 같은 와이파이에서 가장 빠릅니다.

1. 차고에서 차량 선택 → **🌐 ONLINE**
2. **방 만들기** (인원 2~4명 선택) 또는 코드 4글자로 **참가**
3. 호스트가 **START** (빈 자리는 호스트가 조종하는 AI가 채움)
4. 호스트가 물리·충돌·아이템 전체를 시뮬 → 전원 동일한 화면
5. 다음 판: 게스트가 "다시 달리기"를 누르면 호스트에게 요청이 가고, 전원 모이면 자동 시작
6. 화면 우상단에 핑(ms) 표시 (게스트만, 호스트는 HOST)

> 기본은 공개 중계 서버(느릴 수 있음). 본인 계정의 브로커가 있으면
> `js/relay-config.js`의 RELAY에 주소·ID·비밀번호를 입력하세요.
> 전원은 자동으로 그 서버로 연결됩니다. 한국과 가까운 리전으로 만들수록 빠릅니다.

## 게임 모드 (메인메뉴 모드 카드에서 선택)

- **🏁 레이싱:** CPU 3대와 3랩 대결 (아이템 없음)
- **🎁 아이템전:** CPU 3대와 아이템 배틀
- **⏱ 타임어택:** 1인 주행, 기록이 전원 공유 순위표(TOP5)에 저장. 순위표에서 👻 대결 버튼으로 고스트와 대결 (반투명 고스트 + 실시간 차이 표시)
- **🌐 온라인:** 시작하기 → 싱글/멀티 선택. 멀티는 2~6명 (2명 이상이면 AI 없이 사람끼리, 1명이면 연습용 AI 3대)

## 게임 방법

- **차고:** ◀ ▶ 버튼(또는 방향키)으로 차량 변경, 트랙 선택 후 RACE START
- **경주:** 자동 가속이 기본. 방향키/WASD·화면 탭으로 조향
  - 화면 왼쪽 터치 = 좌회전, 오른쪽 터치 = 우회전, 양쪽 동시 = 브레이크/후진
  - **DRIFT 버튼**(또는 Shift): 누르면 미끄러지며 차지, 떼면 차지량만큼 미니 터보!
  - 시작 전에는 반투명 L/R 힌트가 뜨고, 출발하면 사라집니다
  - 미니맵을 탭하면 하단 메뉴(재시작·차고·음소거·전체화면)가 열립니다
  - 가드레일 밖으로 나갈 수 없음. 벽에 박으면 감속(+강타 시 대미지)
  - 시안색 부스트 패드 = 가속, 주황 점프대 = 점프(장애물 회피 가능)
  - 오르막은 감속·내리막은 가속
  - HP 바가 바닥나면 💥 폭파 탈락 (AI도 탈락 가능)

| HUD | 설명 |
|---|---|
| 좌상단 미니맵 | 서킷 전체 + 내 차(빨강) 위치 |
| LAP n/3 | 현재 랩 |
| 초록 타이머 | 경과 시간(초) |
| 순위 (1st/4) | 실시간 순위 |
| 속도 + HP 바 | 하단 중앙 |

## 트랙 8종 (차고에서 선택)

| 트랙 | 테마 | 특징 |
|---|---|---|
| 초원 오벌 | 공원(잔디·벤치·호수 부두) | 기본 오벌 3랩 |
| 사막 웨이브 | 사막(선인장·바위) | S자 웨이브 3랩 |
| 도심 헤어핀 | 도심(빌딩·가로등) | 타이트한 헤어핀 3랩 |
| 말굽 서킷 | 공원 | 말굽형 + 시케인 3랩 |
| 대륙 익스프레스 | 사막 | 초장거리 2랩 + 흙 지름길(잔디 커팅) |
| 테크니컬 | 도심 | 연속 S자, 코너링 승부 3랩 |
| 포레스트 | 숲(빽빽한 나무·안개) | 구불구불 2랩 + 점프대 2개 |
| 빌리지 손가락 | 공원 | 8단 손가락 + 흙 지름길, 좁은 길 2랩 |

## 아이템전 (차고에서 ON/OFF, 온라인은 호스트가 결정)

- 시안색 박스를 먹으면 랜덤 아이템 1개 (🎁 버튼·Space로 사용)
- 🚀 BOOST: 1.3초 가속 / 🛡️ SHIELD: 6초간 대미지 1회 흡수
- 💣 MINE: 뒤에 설치, 밟으면 25 대미지 (점프로 회피 가능)
- ⚡ SHOCK: 상대 전원 12 대미지 + 감속

## 조작 버튼 배치

- DRIFT·🎁 버튼이 좌우 1개씩(총 4개). 어느 쪽을 눌러도 동일 동작
- 미니맵 → ✏️ → 편집 모드에서 드래그로 이동, 슬라이더로 크기 조절
- 배치는 브라우저에 자동 저장됨

## 구조

- `js/track.js` — 서킷 수학(중심선·투영·곡률·트랙 정의), three.js 없음
- `js/race.js` — 관성 물리(속도벡터+그립)·AI·랩/순위·대미지/장애물 충돌, three.js 없음
- `js/voxel.js` — 복셀 차량/소품 빌더
- `js/world.js` — 테마별 도로·연석·간트리·장식·조명
- `js/garage.js` — 차량·트랙 선택 화면(3D 턴테이블+프리뷰)
- `js/hud.js` — 미니맵·타이머·HP·탭 입력·효과음
- `js/main.js` — 관성 카메라·게임 루프·폭파 연출
- `classic-2d/` — 이전 2D 포팅 보존
  (원본 [lakshyajain06/SmashyRoad](https://github.com/lakshyajain06/SmashyRoad) Java 15종 1:1 포팅)

## 로컬에서 실행하기

```bash
python3 -m http.server 8000
# http://localhost:8000 열기
```

three.js는 CDN(`cdn.jsdelivr.net`)에서 불러오므로 실행 시 인터넷이 필요합니다.

## 배포

`main` → GitHub Pages (Deploy from a branch, /(root)). 푸시하면 자동 재배포됩니다.

# BLOCKY RACER

복셀 레이싱 게임 (정적 사이트, GitHub Pages).

## 시작

```bash
python3 -m http.server
```

`three.js`는 CDN(jsDelivr)에서 로드됩니다.

## 모드

- **레이싱**: CPU 3대와 3랩 대결 (그리드 셔플 없음, 본인 선두 고정)
- **아이템전**: 부스트·실드·지뢰·쇼크
- **타임어택**: 단독 기록 도전, 고스트 대결 가능
- **온라인 대전**: 4글자 코드 입장, 2~6명, 호스트 권위 시뮬

## 조작

- 화면 좌우 탭 = 조향, 동시 터치 = 후진
- 드리프트 버튼 홀드 → 미니 터보
- 미니맵 탭 = 메뉴

## 트랙 (9종)

초원 오벌, 사막 웨이브, 도심 헤어핀, 말굽 서킷, 대륙 익스프레스,
테크니컬, 포레스트, 빌리지 손가락(지름길 1개), 트랙9(나선 타워 1랩)

## 차량 (15종)

기본 9종 + 상자 전용 6종(F1 SHADOW, GT GOLD, RALLY STORM,
COMET NEO, MONSTER KING, POLICE X).
능력치는 속도·핸들링·내구도 100점 만점 (물리 기반 환산).

## 재화·상자

- 완주 보상으로 코인 획득 (1위 100 → 4위 30, TA 50+신기록 100, 온라인 80)
- 일반 300 / 고급 800 / 전설 2000 (10연차 10% 할인)
- 3★ 코인 / 4★ 코인·레어차 / 5★ 전설차, 상자별 5★ 천장 보장
- 중복 차는 코인으로 전환, 최근 20회 히스토리 공개

## 계정·순위표·친구

- 회원가입·로그인 (ID 선점 + PIN 간이 잠금, 서버 없음)
- 로그인 유지, 기기 기록 계정 이전·병합
- 타임어택 순위표 공유 (MQTT retained), 전체/내 기록 탭, 고스트 대결
- 친구 추가(ID 확인) · 온라인 표시 · 보유차 · 기록 · 방 초대
